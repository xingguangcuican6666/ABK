# ABK UI source origin

This self-contained Android library was imported from the sibling ABK UI design repository at commit `2ad9b29f3f9e0853d53b2f080a40c5462819c040` and adapted to this application's Gradle/Compose toolchain. It does not require that repository to build.

- Public APIs retain the `io.github.xingguangcuican6666.abk.ui` namespace.
- Lucide vector geometry is generated by `scripts/generate-compose-icons.py` from `assets/vendor/icons/icon-data.js` at the repository root. Do not hand-edit `AbkIcons.kt`.
- Font and color/icon license records ship in `src/main/assets/abk/`. The complete LXGW WenKai font family contributes approximately 47.7 MB before packaging.
- Application preferences, credentials, build plans, and device operations do not belong in this module.
