# ABK UI

`(:abk-ui)` is ABK's native design system: the theme, the Lucide icon set and the
Compose components that every ABK screen is built from. It was designed in the
sibling ABK UI design repository and moved here as the single source of truth.

- Public APIs use the `io.github.xingguangcuican6666.abk.ui` namespace.
- `AbkTheme(darkTheme, colorSource, seed, fontFamily, monoFontFamily, reduceMotion)`
  provides `AbkColors`, `AbkTone`, `AbkStatusColors`, `AbkShapes`, `AbkSpacing`
  and the Yozai text family. Material You roles follow the system dynamic colour
  on Android 12+ and fall back to a deterministic Tonal Spot seed below that.
- Lucide geometry in `icons/AbkIcons.kt` is generated by
  `scripts/generate-compose-icons.py` from `assets/vendor/icons/icon-data.js`.
  Never hand-edit it.
- Font provenance and licences ship in `src/main/assets/abk/`; regenerate the
  subset TTFs with `scripts/prepare-fonts.py --src <dir>`.
- Application preferences, credentials, build plans and device operations do not
  belong in this module; it has no state of its own.

No AAR is published. `:app` consumes the module directly.
